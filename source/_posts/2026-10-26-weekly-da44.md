target = [0x8F,0x4C,0xD1,0xA0,0x26,0x3F,0x9B,0xC2,0xD6,0xAA,
          0xE6,0x42,0x84,0x25,0xA8,0x84,0x45,0x51,0x72,0x45,
          0x3D,0xE8,0x65,0xA4,0xCE]
def rol8(x, n):
    n &= 7
    return ((x << n) | (x >> (8 - n))) & 0xFF
def enc(ch, i):
    k1 = (13*i + 90) & 0xFF
    k2 = (i & 3) + 1
    v2 = rol8((ch ^ k1) & 0xFF, k2)
    return (9*i + v2 + 23) & 0xFF
flag = ''
for i in range(25):
    for ch in range(256):
        if enc(ch, i) == target[i]:
            flag += chr(ch)

以下为ai解释

### 第一步：先看"地图"，不要急着读指令

打开 wasm 反汇编，先扫一眼结构：

Plain Text

```
type section:    2 个函数类型
function section: 2 个函数
export section:   导出了 memory 和 check_key
```

关键结论：入口就是 ﻿check_key﻿，它只接受一个参数（输入指针）。这就是你要读的函数。

### 第二步：从入口开始，一行一行"翻译栈"

wasm 是栈式虚拟机——你把每个操作想象成在一个栈上 push/pop。我用你贴的代码带你走前几行：

Plain Text

```
mov  $local0, 0          ; local0 = 0  → i = 0
mov  $local2, 0          ; local2 = 0  → 累加器 = 0
loop:
  i32.ge_u $local0, 0x12 ; i >= 18 ?
  br_if 1                 ; 是就跳出
```

读到这你就知道：这是个 18 次的循环。

继续：

Plain Text

```
i32.add $param0, $local0   ; push (input_ptr + i)
i32.load8_u                 ; 弹地址，push *(uint8*)(ptr+i) = input[i]
i32.const 0x37              ; push 0x37 = 55
i32.mul $local0, 0xB        ; push i*11
i32.add                     ; 弹两个，push 55 + 11i
i32.xor                     ; 弹两个，push input[i] ^ (55+11i)
```

到这里你就写出了第一行公式：

|  |  |  |  |  |  |  |  | Plain Text |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | v | = | input[i] | ^ | (55 | + | 11\*i) |  |

### 第三步：识别"魔法模式"

继续往下：

Plain Text

| 1 i32 rem u $local0 7 2 i32 const 1 3 i32 add 4 call $f0 | ; i % 7 ; (i%7)+1 ; 调 f0 |
| --- | --- |
| 你看到 call $f0 就跳过去看﻿ ﻿， | $f0 是什么：﻿ ﻿ |

Plain Text

```
$f0(a, b):
    a &= 0xFF
    return ((a << b) | (a >> (8-b))) & 0xFF
```

记住这个模式：(x &lt;&lt; n) | (x &gt;&gt; (8-n))﻿ 就是 8 位循环左移 ﻿rol8﻿。以后看到 shl + shr_u + or 三件套，直接认出来是 rol/ror。

所以这行是：

Plain Text

```
v = rol8(v, (i%7)+1)
```

### 第四步：把常量记下来，别猜

继续：

|  |  | Plain Text |
| --- | --- | --- |
| 1 2 3 4 5 6 7 | i32 .const 0x13 ; push 0x13 = 19 i32 add ; v + 19 i32 mul $local0 3 ; i\*3 i32 add ; v + 19 + i\*3 i32 const 0xFF i32 and ; & 0xFF local .set $local1 ; local1 = 这个结果 |  |

写成公式：

Plain Text

```
local1 = (rol8(input[i] ^ (55+11i), (i%7)+1) + 19 + 3i) & 0xFF
```

### 第五步：找到"比对点"

这是最关键的——你要找程序拿什么跟什么比。看最后一段：

Plain Text

```
local.get $local2       ; push 累加器
local.get $local1       ; push local1
i32.add 0x100, $local0  ; push (0x100 + i)
i32.load8_u             ; push mem[0x100+i]
i32.xor                 ; local1 ^ mem[0x100+i]
i32.or                  ; 累加器 |= 这个值
local.set $local2
```

最后：

Plain Text

```
i32.eqz $local2        ; 累加器 == 0 ?
```

这就是判定条件。local2﻿ 初始是 0，每次 ﻿|=﻿ 一个非零值就再也变不回 0。所以要让它最后等于0，必须每一位都满足：

|  |  |  |  | Plain Text |
| --- | --- | --- | --- | --- |
| 1 | local1 | == | mem[0x100+i] |  |

最后写出py脚本解密

```python
def rol8(x, n):
    n &= 7
    x &= 0xFF
    return ((x << n) | (x >> (8 - n))) & 0xFF
def ror8(x, n):
    return rol8(x, (8 - n) & 7)
```

# 从 IDA 数据段抄下来的 18 个密文字节

target = [0x19,0xCA,0x79,0x2F,0x5F,0xA8,0xAB,0xD3,
          0x22,0x93,0x5D,0x65,0x5A,0x09,0x48,0xFA,

    s = math.isqrt(n)

def bsgs(g, h, p):
    g %= p
    h %= p
    if h == 1:
        return 0

    table = dict()
    # baby step: store g^j -> j

    return None
