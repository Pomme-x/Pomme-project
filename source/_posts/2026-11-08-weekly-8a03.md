### 一、C：\*p++ 逐字节遍历

\*p++ 等价于 \*(p++)，先取 p 当前指向的那个字节，再让 p 往后走一格。++ 优先级比 \* 高，但 p++ 是「先返回旧值，再自增」，所以取值用的是旧地址。

```c
#include <stdio.h>
int main(void) {
    char s[] = "hello";
    char *p = s;              // p 指向 'h'
    while (*p != '\0') {      // 解引用：看当前这个字节是不是结尾
        printf("%c ", *p);    // 用旧地址取字符
        p++;                  // 再往后走一格
    }
    printf("\n");
```

// 和上面完全等价，但更短：

```
    p = s;
    while (*p) {              // 非 0 就继续
        printf("%c ", *p++);  // 先打印 *p，再 p++
    }
    printf("\n");
    return 0;
}
```

输出都是h e l l o

写法

意思

结果

\*p++

先取值，p后移

用到的旧地址的内容

(\*p)++

把p指向的那个字节+1

p 不动 内容变了

\*++p

p先移动

用到的是新地址的内容

指针 +1 走多远取决于\*指针类型

```c
int  a[] = {1, 2, 3};

```

处理字节一定用 ﻿unsigned char﻿。 ﻿char﻿ 在多数平台是有符号的，﻿0x80﻿ 以上会被当成负数，做异或、比较时全乱。逆向里看到 ﻿_BYTE \*﻿ 就是 unsigned char。

sizeof → 要减，因为它把 \0算进去了

strlen → 不要减，因为它没算 \0

strlen 给的是「有效长度」，sizeof 给的是「总容量」。有效长度直接用，总容量要剪掉结尾那一格。strlen 只能用在以  \0 结尾的内存上。如果是从文件里读出来的一段裸字节、中间没有 \0，strlen 会一路数到越界，返回一个乱数甚至崩掉。那种情况必须用读到的长度，不能靠 strlen。
